# Brand Assets & Logo Directory

This directory stores the official brand vector (SVG) and raster (PNG) logo files for Tutor Time and its four individual services.

Until final design assets are delivered by the project owner, front-end templates display neutral, accessible placeholder boxes styled via `.logo-placeholder` in `css/components.css`.

## Asset Guidelines
1. **Format:** Prefer scalable SVG files for crisp rendering across high-DPI (Retina) screens.
2. **Background:** Transparent backgrounds required (no white or solid backing squares).
3. **Contrast:** Ensure assets have sufficient contrast against dark backgrounds (`#0f0f14` and `#14141c`).
4. **Placement:** When delivered, place the files in this folder and update image tags in `index.html` and the respective `/services/*.html` pages.
